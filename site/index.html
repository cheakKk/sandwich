How it works

From sign-in to a live session in four steps.

  1. 01

    Sign in

    Hosts sign in with Google or GitHub. Guests never need an account.

  2. 02

    Add your key

    Use your own Anthropic or OpenAI key. It is held only while the session runs, and the agent never sees it.

  3. 03

    Launch

    Start with an empty workspace or a public GitHub repository. Pick Claude or Codex.

  4. 04

    Invite

    Send a single-use link. A guest opens it, types a name, and is in.

Live, together

One agent, many hands.

Everyone sees what the agent is doing and whose order it is on. If you prompt while it is busy, you are told what you are queued behind, and your message waits its turn.

Memory

Memory that follows the project.

Decisions, finished work and open tasks are saved with the project, so the next session, or the next person, picks up where this one stopped. Saving a summary never throws away what was already recorded.

Cost

Costs you can see.

Every turn is credited to whoever started it. Set a daily token cap for any guest and a budget for the whole session, so a busy afternoon never turns into a surprise.

Two settings

You decide how much the agent can do without asking.

Guarded

The default. Anything the agent wants to do beyond reading waits for an op to approve it, and you see the full command first.

Trusted

For teams you trust. Tools run without asking, inside an isolated sandbox, with a daily token cap for guests and a budget for the session. Only the owner can switch it, and everyone is told.

Security

What we protect, and what we do not.

Built and tested today

  • Anything beyond reading needs an op to approve it, and the approval shows the full command.
  • Reading is limited to visible files inside the project folder.
  • Invite links work once and expire. Tokens never travel in a web address.
  • The agent runs with a clean environment: no owner token and no stray secrets.
  • Every turn, tool call and cost is recorded against a person.

Before the beta opens

  • Each session in its own isolated sandbox, proven by tests that try to escape it.
  • Your API key held by a proxy and never inside the sandbox.
  • A security review by someone who did not build it.
  • Written confirmation of the AI providers' terms for a hosted product.

No tool can promise that an AI agent will never be talked into a mistake. That is why a person approves what matters, and why we say plainly what is and is not protected. The full list is in our security notes.
